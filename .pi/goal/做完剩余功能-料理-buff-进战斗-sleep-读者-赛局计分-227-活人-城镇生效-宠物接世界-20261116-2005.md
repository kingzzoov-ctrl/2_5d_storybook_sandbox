## 要做的六项(每项都已有可查落点,不是从零设计)

1 **料理 buff 进战斗** —— `combat/weapons.ts` 的 `combatantStats(level, equippedIds, buffs)` 已定义 `BuffInput{atkMul,hpMu,critRate,critDmg,allyCount}`,但 `world_sim.ts` 的调用点**恒不传第三参**;今天只有 `hpFlat` 到达玩家(经 `maxHpForLevel`),其余 9 个字段无消费者。
2 **`SLEEP` 的世界侧读者** —— `actions/sleep.ts` 只登记"谁在睡、睡到何时",慢帧没有任何读者。
3 **赛局真的计分** —— `actions/start_party.ts` 有 `addScore`/`endParty`,但**没有生产调用点**,分数永远不动。
4 **227 对**活人**的困人半边** —— 今天只对 `DownedState`(幽灵泡泡)生效;手册要求"对活人连中 3 发 ⇒ 装进大泡泡 5 秒"。
5 **城镇配置接 `spawner`** —— `MODIFY_TOWN` 登记了 per-room 配置,但 `mobs/spawner.ts` 仍读常量 `TOWN_SAFE_RADIUS` ⇒ 改造一点不生效。
6 **宠物接世界** —— `BREED_TAME` 的宠物只是动作模块里的 Map;`net/schema.ts` 的 `WildlifeState.tameOwnerId` **没有写入者**,世界/AI 不知道宠物被驯服。

## Acceptance criteria(全部可客观核验)

1. **料理 buff 真的进战斗**:`world_sim.ts` 里 `combatantStats` 的第三参**不再是空对象形态**;`atkMul` / `critRate` / `critDmg` 中至少一个具备**可红断言**(吃某料理后、同一 `level` 与装备下该值不同;期望值取**手册或内容表的字面量**,不取实现常量)。
2. **`SLEEP` 有世界侧读者**:存在**可查读口**能观察"该玩家正在睡 / 睡到何时",且**既有回血数值不变**(`WS-03` / `WS-FND-11-afk` / `WS-FND-26` 全绿)。
3. **赛局有生产调用点**:分数随**游戏进程**变化(不是只有测试调用 `addScore`);`partyStateOf` 能读到由事件累积出的非零分数,结算名次随之变化;有可红断言。
4. **227 活人半边**:要么实现(一个状态 + 计时器,并说明为何不与 `DownedState` 的 `BUBBLED` 形成两份表示),要么在 `TASK-96` 里**明确列为未做并写清卡点**。二者都算达成,**不许含糊**。
5. **城镇配置生效**:安全区判定按 per-room 配置;`MODIFY_TOWN` 改成 8 之后,原本在 24 以内、8 以外的点**不再**算安全区内部;默认(未改造)行为与今天**逐字一致**。
6. **宠物被世界看见**:`tameOwnerId`(或等价的投影接口)有**真正的写入者**且有生产调用点;有一条断言证明"驯服后世界侧能看到主人"。
7. **门禁绿**:`node scripts/verify.ts --all --strict-reach --strict-taut --strict-inert --strict-selfcheck` 退出码 0、行首 `✗` 计数 0;类型错误基线不增(**261 / 129**);`README` / `HANDOVER` / `TASK-96` / `COMPLETION-CRITERIA` 的用例数与套件数与实测一致;`HANDOVER` sha256 表自洽。
8. **已推送**:改动 commit 并 push 到 `origin/main`;`git rev-parse HEAD` 与 `git ls-remote origin main` 逐字符相同;`git status` 只有未跟踪的 `.pi/`。
9. **每条新判据做过注入验证**:改坏实现 ⇒ 该判据红 ⇒ **逐字节还原**(给出还原前后 SHA256 相同)。
10. **不实的说法全部收敛**:这六项里没做到的部分(某个 buff 字段仍无消费者、某个半边未建模、某项需要冻结层或 owner 裁决),必须在 `docs/TASK-96-action-landing-gaps.md` 与 `docs/COMPLETION-CRITERIA.md` 里**逐条列出**,不得写成"已完成"。

## Boundaries(不得越过)

- **不改 `shared/**`(冻结层)与 `shared/testing/harness.ts`**。若某项必须改冻结层(例如 `gravityMul` 要给 `integrateVertical` 加参数位、buff 上屏要给 `FIELD_TABLE` 加字段)⇒ **列为未做并写清原因**,不许硬改。
- 不加运行时依赖(`dependencies` 保持 `{}`);禁用 `enum` / 构造函数参数属性 / `namespace` / 装饰器;相对导入必须以 `.ts` 结尾。
- 注入还原**不许**用 `git checkout` / `git reset` / 通配符删除:必须用原始字节写回并校验 SHA256。
- 不 commit `.pi/`;不 `git push --force`。
- **不替 owner 决定**破坏性 / 存档类语义(`RESET_WORLD` 的存档政策、世界重置的数据去留)。
- **不为凑绿放宽判据**:不许把 `eq` 换 `ok(...)`、不许加重试包裹、不许删断言、不许把断言右侧改成被测模块自己的导出常量(`--strict-taut`)。
- 同一文件不做并行编辑:并行线按**文件互斥**切分。
