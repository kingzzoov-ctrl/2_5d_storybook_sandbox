# 目标

把 `2_5d_storybook_sandbox` 从「门禁全绿但玩家感知不到的机制一堆」推进到**项目自己写下的完成定义**:`docs/COMPLETION-CRITERIA.md` 的档 B(服务端能完整跑一遍)与档 C(核心玩法机制成立)全部闭合,且 `docs/TASK-96-action-landing-gaps.md` 里那 17 个未接线动作**逐个有执行层、能从网络上行通道触达、在浏览器里能被玩家感知**。

按依赖顺序分轮落地;每轮都是「实现 + 断言 + 注入验证 + 门禁全绿 + 提交推送」的完整闭环,任何一轮都不留下红的中间态。

## 验收判据(执行后我逐条自查,全部可机检)

1. **门禁**:每轮结束跑 `node scripts/verify.ts --all --strict-reach --strict-taut --strict-inert --strict-selfcheck`,**退出码 0 且行首 `✗` 为 0 项**;类型错误不超过基线(261 条 / 129 指纹);自检 30/30。
2. **22 个动作全部有执行层**:`dispatchAction` 里 **不再有** `kind:'NOT_IMPLEMENTED'` 的动作;每个动作至少一条**行为断言**(断言它产生了可观测副作用,不只是"回了 OK"),且 `tests/WS-FND-18` 的「未接线集合」为空。
3. **每个动作可经网络触达**:`ws_server` 提供 `t:'action'` 上行 → `room.dispatchAction` → `t:'actionResult'` 回执;有一条**真 socket** 的端到端断言(发送 → 副作用 → 回执),含越权被 `PERMISSION` 拦下的负对照。
4. **客户端可感知**:浏览器里能操作并看到结果 —— 建造/破坏(含目标格的选中反馈)、背包与物品增减、地面掉落物可见可拾、容器/自动化/宠物/睡觉/派对各有入口与界面反馈;改动以现有 `client/src/**` 的 HUD 风格实现,不引入前端框架。
5. **档 C 四项闭合**:
   - 9 种动态房间**每种**都有玩家可感知的增益(含把牧场/炼金室/温室/百货店四个系统真的建起来,或给出等价的、玩家可信的机制并记录该裁决);
   - 料理 buff 有**生产者**:`WorldSim` 持有玩家身上的 `FoodBuff`,`hasMealBuff` 在运行期可取到真值,`CANTEEN_MEAL_MUL` 能被真实触发;
   - 三件死道具(733 羽毛笔 / 435 复活旗 / 227 泡泡水枪)从 `implemented:false` 变为**真的可用**,并有行为断言;
   - 相机跟随权威位置,WASD 不再同时平移相机(角色走出画面不再是巧合)。
6. **§五 六项未实测**逐条落地:z 轴接入并有断言;FPS 用可复现命令测出数字(标明 headless/swiftshader,不冒充真机);colyseus.js 打包兼容性实测;`RoomSchema`↔`prediction.ts` 的 `Snapshot` 逐字段对齐表 + 断言;#245 玩家可达性;knockback 与移动的优先级给出裁决 + 断言。
7. **每轮纪律**:新断言先做**注入验证**(把机制改坏 ⇒ 对应断言必须红,且报出是哪一条),再做**字节级还原**(还原后 SHA-256 与注入前一致);还原后复跑全绿。
8. **推送**:每轮一个提交,推送 `origin/main`;推送后 `git ls-remote origin main` 与本地 HEAD 一致、`git status` 除未跟踪的 `.pi/` 外干净。
9. **文档与实测一致**:`README.md` / `docs/HANDOVER.md` 的数字表、`docs/TASK-96-action-landing-gaps.md` 的归属表、`docs/COMPLETION-CRITERIA.md` 的 `[x]/[~]` 标记,全部与门禁实测一致;被我改成 `[x]` 的每一条都必须有一条断言钉住。
10. **仓库纪律不回退**:`dependencies = {}`(零运行时依赖)、无 `enum`/构造函数参数属性/`namespace`/装饰器、相对导入带 `.ts` 后缀、`shared/**` 冻结层不变量 17/17、内容基线指纹可解释。

## 边界(不做的事)

- **不改冻结内容表的既有语义**:`shared/constants/items.ts` 等现有表只准新增条目(且必须显式记一次内容裁决、说明为什么既有内容不够),不准改动/删除既有 id 的语义;内容指纹变化要在文档里可解释。
- **不放宽既有断言来求绿**:只允许「驱动窗口加长 / 夹具显式隔离(如 `mobs:false`)/ 把过严的等号改成有理由的不等号」这类修正,且每处都要写明理由;不允许删测试、不允许把断言改成恒真。
- **不伪造实测**:每个「能做到」的声明都配一条可复现命令与它的真实输出;做不到的写「做不到 + 为什么」。
- **不引入新的运行时依赖、不引入网络或外部服务**(LLM 炼金一类需要外部服务的机制,做成「可注入的本地实现 + 明确的未接线标注」,不假装它已工作)。
- **不动** `shared/testing/harness.ts`(保持 throw-style)、`scripts/gate-selfcheck.ts` 的既有区分力用例、`.pi/`(本地状态不跟踪)。
- 不做 `git rebase` / `force push`;不改远端历史。
