## Boundaries(不得越过)

- **不改 `shared/**`(冻结层)与 `shared/testing/harness.ts`**;凡被冻结层挡住的字段只能记为未实现并写进文档。
- 不加运行时依赖(`dependencies` 保持 `{}`);禁用 `enum`/构造函数参数属性/`namespace`/装饰器;相对导入必须以 `.ts` 结尾。
- 还原注入**不许**用 `git checkout`/`git reset`/通配符删除:必须用原始字节写回并校验 SHA256。
- 不 commit `.pi/`;不 `git push --force`。
- **不得把边界说成已实现**:箱内容不在 wire、`SLEEP` 只有登记没有世界侧读者、`RESET_WORLD` 宿主能力缺失、`PlayerState` 无按件明细(所以 `USE_ITEM` 的 `itemId` 由客户端自报)—— 必须在 `TASK-96`/`COMPLETION-CRITERIA` 里保持如实表述。
- 不替 owner 决定破坏性/存档类语义(存档政策、世界重置的数据去留)。
- 不为凑绿放宽判据(不许把 `eq` 换 `ok(...)`、不许加重试包裹、不许删断言)。
