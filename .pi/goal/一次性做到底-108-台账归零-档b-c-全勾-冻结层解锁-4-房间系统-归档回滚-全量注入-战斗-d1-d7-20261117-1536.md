## Boundaries

- **不新增 owner 未裁的产品决定**:平衡数值、存档政策(D-06 已裁归档)、破坏性语义仍由 owner 定;本批已给的 9 条裁定按字面执行。
- `shared/**` 本批**允许**改(owner 已授权),但必须同批更新 `FREEZE.md` 与门禁里的冻结清单并说明每一处放宽;`shared/testing/harness.ts` **永不改**。
- **不加依赖**(`colyseus` 等现状不动);禁 `enum` / 构造函数参数属性 / `namespace` / 装饰器;相对导入以 `.ts` 结尾。
- **不为凑绿放宽判据**:不许 `eq`→`ok(...)`、不许重试包裹、不许删断言、期望值不许取自被测模块。
- 注入还原**只用原始字节写回**并校验 SHA256;**不许** `git checkout` / `git reset` / 通配符删除。
- 不 commit `.pi/`;不 `git push --force`。
- 并行线按文件互斥;不并发跑 `verify.ts --all`(只在收口跑)。
- 类型错误**不得增加**(以当前 261 条 / 129 指纹为上限;新增代码引入的错误必须先修掉再加功能)。
