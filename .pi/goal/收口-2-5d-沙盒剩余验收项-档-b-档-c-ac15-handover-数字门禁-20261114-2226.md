# Boundaries

- 不新增运行时依赖、不引入构建步骤(Node 24 原生类型擦除,零依赖、无 build)。
- 不违反可擦除语法禁令:全仓不得出现 `enum` / 构造器参数属性 / `namespace` / 装饰器;相对导入必须以 `.ts` 结尾。
- 不改 `shared/**`(冻结层)与 `shared/testing/harness.ts`;不改内容基线锁指纹,除非是把内容表与基线同步的正当更新并明确说明。
- 不删内容表条目:`733 / 435 / 227` 必须保留。
- 不做「返回 `OK` 但无副作用」的动作接线;仓库内无落地点的动作保持显式 `NOT_IMPLEMENTED`。
- 临时残留清理只走 `scripts/clean-temp.ts`;不手工删、不用通配符。
- 不提交 `.pi/`;不改写已发布的历史(若确需 force-push,先说明并取得同意)。
- 每次提交前门禁必须全绿;一次提交 = 一个可回滚的完整增量。
- `verify.ts --all` 会造成写 `dist/` 等副作用,不与其它的写操作并发。
