## 1 三处真 bug(是「做错了」,不是「还没做」)

### 1.1 T 键的 NPC 对话从未发出

- **症状**:站在 NPC 旁边按 T,什么都不会发生;查下行也找不到任何 `NPC_TALK`。
- **根因**:两件事叠在一起 —— 按键守卫先把 `T` 吃掉(判定为调试键),**同一次按键**又被当成「使用道具」,
  于是键位分配到不了对话分支。这不是 NPC 侧没实现,是输入层把它挡掉了。
- **改法**:按键守卫让出 `T`;「使用道具」与「对话」按**目标**分流,不再共用同一次按键。
- **证据**:`verify --only WS-FND-195` 报 `✓ tests/WS-FND-195-overworld.test.ts — [WS-FND-195] 10/10 通过`、
  `用例汇总:10 条通过(1 个套件),跳过 0 项`。「按键不再被吞」这一条**没有单独的用例**,
  它是在主世界落地时随对话链路一起恢复的 —— 所以这里的证据是「对话链路整体可跑」,不是「按键的回归测试」。

### 1.2 入场首帧按 AOI 裁剪,逐帧差量却是整房

- **症状**:远处的怪能看见名字,但**物种与血量恒为空**;有时贴图和血条对不上。
- **根因**:两条路径的裁剪口径不一致 —— 首帧按 AOI(可视范围)裁,后续每帧的差量却按「整个房间」算,
  于是首帧漏掉的实体再也没被补进客户端的实体表。
- **改法**:首帧与差量统一到同一套可见集口径。
- **证据**:同上套件内的 AOI 相关用例;下行帧计数走 `npcFramesSent()` / `terrainFrames` 这类可读计数,
  不靠肉眼。

### 1.3 采集工具按「词条交集」推导 ⇒ 第一把镐造不出来

- **症状**:割草要捕虫网、挖矿要炒菜铲,而第一把镐在自己造出来之前无处可得 —— 卡在死循环。
- **根因**:工具适配不是查表,而是从物品词条做交集推导;推导出的组合与直觉和手册都不一致。
- **改法**:改成**显式的表** —— 斧砍树、镐敲矿、铲挖黏土,其余徒手。
  用「拆除」采原生资源走与采集相同的距离与工具判定。
- **证据**:`tests/WS-FND-154` / `WS-FND-181` 随规则更新(见提交 `1d0924d`)。
  **本轮只重跑了 WS-FND-195 一套**,这两套没有在本轮重跑,所以这里不写「已通过」。

## 2 背包以服务端为准(口径修正,不是加功能)

- **症状**:带着 7 件起始包,背包就只剩 1 件余量;采集、合成、交任务全部走不通。
- **根因**:容量口径错位 —— **一格当成一件**。设计是「负重格 × 每格件数」。
- **改法**:
  - 容量闸:`负重格(Lv.1 = 8) × ITEMS_PER_CARRY_SLOT(20) = 160 件`;储物箱同步为 24 档 × 20。
  - 服务端新增背包下行帧 `{t:'inventory', items, capacity}`:握手后一次、每次动作回执后一次,
    广播循环再按 200ms 节拍兜底比对(掉落/奖励等「动作之外」的变化),**内容没变不重发**。
  - 客户端快捷栏显示真实背包(图标 + 件数 + 手持),点一下换手持;`CRAFT` 的 `have` 改用服务端明细,
    不再靠回执估算。
- **证据**:`tests/WS-FND-194-inventory-downlink.test.ts` 新增;`WS-07/13`、`FND-25/31/129/148/152/155`
  的容量断言随口径更新(见提交 `4d3a8e6`)。**这些套件本轮未重跑**,只重跑了 WS-FND-195。

## 3 主世界「晨曦群岛」

- 世界(`shared/world/overworld.ts`,**确定性生成,两端各算一遍**,不需要下发整图):
  - 圆角方形海岸 + 噪声扭曲的 Voronoi 群系:草甸 / 河谷 / 绯樱 / 竹林 / 溶洞 / 绿洲 / 甜点 / 云海 / 遗迹 + 灯塔岛;
  - 台地、环山、沙丘、两条河、三片湖、熔岩池与巧克力池;
  - 晨曦镇(广场 / 喷泉 / 工坊街 / 酒馆 / 集市 / 炼金塔 / 民居)、八处营地、八座 Boss 祭坛;
  - 环路 + 放射路,过水架栈桥,高差处一次一层并放台阶;
  - 资源按群系撒布(30 种自然资源 + 18 种地标),挡路物件互不相邻。
- 通行规则(`shared/world/passable.ts`):墙 / 树 / 矿 / 家具 / 地标挡路;深水进不去;陡坎要台阶或跳;贴墙可滑行。
  **服务端落点、生物位移、刷怪落点都走同一份**;草丛、花、作物可以踩过去。
- 节奏:围着玩家刷怪,离所有玩家 80 格外的怪离场;镇区是安全区;自然资源采走 120 秒后长回来;
  世界自带的建筑与地标拆不掉。
- `play.ts` 默认 `--world overworld`;设计图的 4 位 NPC 名册保留给既有测试(名册可切换)。
