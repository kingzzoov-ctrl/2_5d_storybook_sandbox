## 0 之前为什么"就是一堆像素块"

三件事叠在一起,互相掩盖:

| # | 事实 | 位置 |
| :-- | :--- | :--- |
| 1 | 客户端画的是**本地硬编码 demo 世界**:64×64、行列式正弦起伏 + 一条正弦河、地板槽位 `1+(gx+gy)%3` 循环 | `client/src/stage/demo_world.ts`(改前被 `three/boot.ts` 直接调用) |
| 2 | 服务器世界**根本不过 WS**:`chunkWireBytes` / `diffChunkVersions` 只有单测在用,线上没有 chunk 下行 | `shared/net/delta.ts` |
| 3 | 地形顶点色**只按海拔层**取色,`base`(草/沙/岩/水)与 `floor`(路/广场/砖)不进颜色路径 ⇒ 全世界只有 4 色 | `client/src/stage/terrain_vcolor.ts`(改前 `faceColor(elevLayerOfZ(z), true)`) |

修法对应三处:`shared/world/design.ts`(设计图)、`client/src/stage/design_world.ts`(客户端画同一张图)、
`terrain_vcolor.ts` 的 `BASE_TOP_RGB` / `FLOOR_TOP_RGB` / `topColorOf`(材质色)。
**已知边界**:世界**改动**(玩家盖/拆)仍不同步到客户端 —— 那要真正的 chunk 下行,是下一刀。

## 1 尺度与海岸线

- 边长 **192×192** 格(`DESIGN_SIZE`),出生点 `(96,96)`。
- 海岸线是**三个谐波叠加**的极角函数:半径 68..88,所以有**海湾与岬角**,不是圆。
- 自海岸向内 6 格是**沙滩环**(`GOLD_SAND`)。
- 陆地 19173 格 / 海 17691 格 / 沙滩 2837 格。

**两条设计纪律**(都是踩过才写下来的):

1. **区心不许压在中轴上**。四条主路沿 `x=96` / `y=96` 走 3 格宽;把湖心/崖顶/跑道心放在中轴上,
   会被主路从正中劈开(实测:温泉眼被盖成路面、跑道内场整条消失)。
2. **主路不许穿过广场内部**。营地是**终点**不是通过点;不跳的话广场中心那 8×8 大理石
   (以及纪念碑/篝火)会被路盖掉(实测 `(96,96)` 变成星光夜路砖 + 一盏路灯)。

## 2b 八大群系落点(2026-11-26 新增)

手册 §4.2 的「八大群系 24 种野生物」现在有了地图落点:每个区在 `REGION_BIOME` 里声明自己的
群系键(逐字对齐 `server/src/mobs/spawner.ts#BIOME_SPAWN`),刷怪按格查 `biomeAt(x,y)`。

| 群系键 | 落点区 | 说明 |
| :--- | :--- | :--- |
| `MEADOW` | camp / meadow / track | 出生点与开阔草原;兜底群系 |
| `VALLEY` | farm / marsh | 河谷耕地与低洼湿地 |
| `SAKURA` | grove | 竹林(花木林) |
| `CAVERN` | mine | 矿丘 |
| `OASIS` | lake / spring | 湖与温泉 |
| `DESSERT` | dunes | **本轮新增的沙丘区**(不给它块地,沙漠野生物就永不出现) |
| `SKYSEA` | highland | 高地云海 |
| `RUINS` | ruins | 遗迹 |

- 判据:`WS-FND-181` 断言 **8 个键都被用到** + 群系表键数 == 区数(多一个键会静默失效)。
- 实测(20000 帧 / 192×192):存活 46 只,`{"VALLEY":6,"CAVERN":5,"MEADOW":14,"DESSERT":4,"OASIS":6,"RUINS":6,"SAKURA":2,"SKYSEA":3}` —— 8 个群系全被刷到,违例 0。
- 已知未做:刷怪**速率**仍按兜底群系加权(每格一个预算要另做);读档恢复生物入册时仍用兜底群系。

## 3 道路

- **环形主干道**:半径 38~40,3 格宽。
- **四条主路**:沿 `x=96` / `y=96`,3 格宽,从广场四边出去。
- 主路材质 = **309 萤光星光夜路砖**:它自带「夜间发光 + 阻止野怪刷新」(`shared/constants/items.ts` 的 note)
  ⇒ 主干道同时是**夜里也安全的动线**。主干道 1676 格。
- 主路伸出海岸的那一段改成 **310 水上浮木栈桥**(210 格),超过 14 格就停(不把路画到海对面)。
- **路灯 522** 沿环路与主路每 12 格一盏(灯也驱怪),共 143 个物件格。

## 5 怎么用

```bash
# 设计图(192×192,推荐)
node scripts/play.ts --world design --host 0.0.0.0 --dist

# 与改前逐字一致的空世界(缺省)
node scripts/play.ts --host 0.0.0.0 --dist
```

- `--world design` 时边长缺省 = `DESIGN_SIZE`(192);显式 `--size` 可覆盖(那是"换边框",区坐标不会缩放)。
- 服务器:`assemble({ design: true })` ⇒ `createHost()` 在 `restoreWorldFromDb` **之前**盖图。
  ⚠️ 顺序是语义:读档只覆盖库里有的块 ⇒ 先盖图,存档里玩家改过的地形才盖得住它。
- 客户端:`buildDesignChunks()` 把同一张图切成 12×12=144 块(面数 37881 < `FACE_BUDGET` 800000)。

## 6 明确的非目标

- 不做多岛 / 多维度 / 多层地下。
- 不做程序化叙事;每个区只有一句"设计意图"(见 `REGIONS[].intent`)。
- 不做 chunk 下行(见 §0 已知边界)。
